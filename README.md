# Liwip Store SDK releases

Release packages of the Liwip Store SDK for React Native. Each release carries its own installer.

## Install

From the host React Native project, with the tag Liwip sent you:

```sh
curl -fLO https://github.com/keystonecommerce/liwip-commerce-sdk-releases/releases/download/<tag>/liwip-store-install.mjs
node liwip-store-install.mjs   # --check-only checks compatibility without installing
```

## Tags

`<partner>-<env>-v<version>`. `test` releases are pre-releases for integration and QA; `prod` releases ship the same packages to production.
